# Ответы на отзывы Wildberries

Скил для продавца WB: агент забирает отзывы без ответа, группирует их, пишет ответы по правилам площадки
и публикует **только те, что пользователь утвердил**. Ничего не публикуется молча.

## Когда применять

- «Ответь на отзывы на WB», «разбери отзывы за неделю», «что пишут про артикул 12345678».
- «Покажи негатив 1–3 звезды и предложи ответы».
- Регулярная рутина: раз в день закрыть все отзывы без ответа.

Не применяй для вопросов покупателей (это другой раздел кабинета WB) и для отзывов на чужие товары.

## Что нужно

| Что | Откуда |
|---|---|
| MCP-сервер `wb` из `tkbk-online/tkbk-mcp` | локально по `npx` (бесплатно) или облако `https://mcp.tkbk.online/mcp/wb` |
| Токен WB `WB_TOKEN` | Кабинет продавца → Настройки → Доступ к API → категория **«Вопросы и отзывы»** (для остатков и цен — ещё «Аналитика», «Цены и скидки») |
| Ключ TKBK `cr_…` | только для облачного MCP: https://tkbk.online/account |

Проверка перед работой: в списке инструментов есть `wb_feedbacks` и `wb_answer_feedback`. Если нет — подключи сервер
(команды ниже) и попроси пользователя перезапустить агента. Токен никогда не проси вставить в чат: он живёт в
переменной окружения или в заголовке MCP-подключения.

```bash
# локально (токен остаётся на компьютере)
claude mcp add wb -e WB_TOKEN=ваш_токен -- npx -y github:tkbk-online/tkbk-mcp wb
# облако TKBK (ничего не устанавливать)
claude mcp add --transport http tkbk-wb https://mcp.tkbk.online/mcp/wb \
  --header "Authorization: Bearer cr_…" --header "x-wb-token: …"
```

Cursor / Claude Desktop: конфиг в README репозитория https://github.com/tkbk-online/tkbk-mcp.

## Порядок работы

1. **Собери отзывы.** `wb_feedbacks` с `take: 100`; если вернулось ровно 100 — повтори с `skip: 100, 200 …`, пока не
   кончатся. Инструмент отдаёт только отзывы без ответа: `id`, `product`, `article`, `rating`, `text`, `pros`, `cons`,
   `createdDate`.
2. **Сгруппируй** и покажи пользователю сводку одной таблицей: сколько всего, сколько по оценкам 5 / 4 / 1–3,
   топ-3 товара по числу отзывов, топ-3 повторяющиеся претензии (размер, брак, доставка, несоответствие фото).
3. **Напиши черновики** по правилам из раздела «Как писать». Один отзыв — один ответ. Выведи таблицу:
   `№ | артикул | оценка | отзыв (кратко) | ответ`.
4. **Спроси подтверждение.** Пользователь может: утвердить все, утвердить часть (по номерам), поправить текст,
   пропустить. Пока ответа нет — не публикуй.
5. **Опубликуй** утверждённые по одному: `wb_answer_feedback` с `id` и `text`, параметр `confirm: true` — только после явного «да» от пользователя.
   Между вызовами не торопись: при `429` подожди секунду-две и повтори тот же отзыв.
6. **Отчитайся**: сколько опубликовано, какие пропущены и почему, какие отзывы требуют человека (см. «Эскалация»).

## Как писать ответы

- Русский язык, обращение на «вы», 2–5 предложений, без капслока и восклицаний через слово. Лимит WB — 5000 знаков,
  норма — 300–600.
- Начни с благодарности или сочувствия по существу: назови товар или проблему словами покупателя, не шаблоном
  «спасибо за отзыв».
- **5 звёзд**: благодарность + одна деталь из отзыва + мягкое приглашение посмотреть другие товары бренда (без ссылок).
- **4 звезды**: благодарность + признать замечание + что сделаете.
- **1–3 звезды**: извиниться за ситуацию (не спорить, даже если покупатель неправ), объяснить без оправданий, предложить
  решение: возврат / обмен через кнопку в заказе WB, проверка партии, уточнение размерной сетки. Если претензия к доставке
  или пункту выдачи — объяснить, что это зона WB, и всё равно извиниться.
- **Запрещено**: обещать компенсации, скидки, подарки и «перезвоним» (у продавца нет контактов покупателя); просить
  изменить оценку или удалить отзыв; указывать телефоны, сайты, Telegram, другие площадки — WB блокирует такие ответы;
  переходить на личности; раскрывать внутренние данные (поставщик, закупка, склад).
- Не копируй один текст во все ответы: WB и покупатели это видят. Меняй структуру и формулировки.
- Если отзыв без текста (только оценка) — короткая благодарность в одну-две фразы или пропуск по решению пользователя.
- Если пользователь дал «тон бренда» (ты/вы, эмодзи, подпись) — следуй ему. Без указаний эмодзи не используй.

## Эскалация — не отвечай сам, покажи пользователю

- Угроза здоровью, травма, аллергия, «подделка», «контрафакт», упоминание Роспотребнадзора или суда.
- Обвинение в обмане с конкретными суммами, спор о возврате денег.
- Отзыв явно не о вашем товаре или похож на спам / конкурента.
- Повторный негатив по одной партии — предложи пользователю проверить партию, а не только ответить.

## Формат итогового отчёта

```
Отзывы WB за <период>: всего N без ответа
Опубликовано: K (список id)
Пропущено: M — причины
Требуют человека: J — кратко суть
Повторяющиеся проблемы: …
```

## Ошибки

| Ответ | Что значит | Что делать |
|---|---|---|
| `401` от WB | токен неверный или без категории «Вопросы и отзывы» | попросить пользователя перевыпустить токен с нужной категорией |
| `429` | лимит WB (отзывы — 1–3 запроса в секунду) | подождать `Retry-After`, сервер MCP сам повторяет чтение; запись повторить вручную |
| `401` / `403` от mcp.tkbk.online | нет ключа TKBK или нет подписки на MCP | https://tkbk.online/mcp |
| Инструментов `wb_*` нет | сервер не подключён | команды выше, перезапуск агента |
