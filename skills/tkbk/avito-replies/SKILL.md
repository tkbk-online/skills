# Ответы в чатах Авито

Покупатель на Авито ждёт ответ минуты, а не часы. Скил собирает непрочитанные чаты по объявлениям, пишет ответы по
правилам продавца и отправляет только то, что пользователь утвердил. Каждое отправленное сообщение уходит от имени
аккаунта пользователя, поэтому без подтверждения ничего не отправляется.

## Когда применять

- «Ответь на непрочитанные в Авито», «что спрашивают по объявлению X».
- «Отвечай на вопросы о наличии и цене по шаблону, остальное покажи мне».
- Регулярно: раз в час разобрать новые сообщения.

## Что нужно

| Что | Откуда |
|---|---|
| MCP `avito` из `tkbk-online/tkbk-mcp` | `avito_chats` (`unreadOnly: true`), `avito_messages` (история чата), `avito_items` (свои объявления), `avito_send_message` (запись) |
| `AVITO_CLIENT_ID`, `AVITO_CLIENT_SECRET` | Кабинет Авито → «API для бизнеса» (OAuth client_credentials; токен сервер получает сам и не хранит) |
| Тариф с доступом к Messenger API | иначе чаты недоступны (ошибка `403`) |

```bash
claude mcp add avito -e AVITO_CLIENT_ID=ид -e AVITO_CLIENT_SECRET=секрет -- npx -y github:tkbk-online/tkbk-mcp avito
# облако: https://mcp.tkbk.online/mcp/avito, заголовки x-avito-client-id и x-avito-client-secret
```

Секрет — в окружении или заголовке, не в чате.

## Настройка продавца (спроси один раз и запомни в сессии)

Перед первым ответом уточни у пользователя и держи в памяти сессии:

- **Наличие**: какие объявления актуальны (по умолчанию — все со статусом `active` из `avito_items`).
- **Торг**: нет / до N % / «предлагайте» — и минимальная цена по позициям, если есть.
- **Адрес и время**: где и когда смотреть, можно ли называть точный адрес в чате (по умолчанию — только район
  и «точный адрес после договорённости»).
- **Доставка**: Авито Доставка да/нет, другие способы.
- **Контакты**: телефон в чате не называть, если пользователь явно не разрешил.
- **Тон**: «вы», коротко, без эмодзи — если не сказано иное.

## Порядок работы

1. `avito_chats` с `unreadOnly: true`, `chatTypes: ["u2i"]` (чаты по объявлениям). Чаты между пользователями
   (`u2u`) и от Авито (`a2u`) — только показать, не отвечать.
2. Для каждого чата — `avito_messages` (последние 20): пойми, что спросили и что уже отвечали. Объявление —
   по `itemId` из чата, данные — из `avito_items`.
3. Классифицируй: наличие · цена / торг · характеристики · адрес / время · доставка · «ещё актуально?» · спам /
   мошенничество · агрессия · не по теме.
4. Черновики по правилам ниже. Таблица: `№ | объявление | собеседник | вопрос | ответ | действие`.
   Действие: `отправить` / `показать пользователю` / `пропустить`.
5. Подтверждение пользователя. Затем `avito_send_message` для утверждённых с `confirm: true` — только после подтверждения.
6. Отчёт: отправлено, передано человеку (с причиной), пропущено.

## Как отвечать

- 1–3 предложения, на «вы», сразу по сути. Приветствие — только в первом сообщении чата.
- «Актуально?» → «Да, в наличии» + одна фраза, когда можно посмотреть / забрать.
- Цена / торг → по настройке продавца. Если торг запрещён — «цена окончательная, спасибо за понимание». Если
  предложение ниже минимальной — «на эту сумму не готов, но могу за N» только при разрешённом торге.
- Характеристики → только из текста объявления или от пользователя. Не знаешь — «уточню и напишу» и пометь
  пользователю.
- Адрес / время → по настройке; точный адрес — только если разрешено.
- Доставка → по настройке; про Авито Доставку — «оформляйте через кнопку в объявлении».
- Не обещай скидок, резерва «до вечера» и сроков, которых пользователь не называл.

## Не отвечай сам — передай пользователю

- Просьбы перейти в другой мессенджер, перевести предоплату, прислать код из СМС, ссылки на «безопасную сделку» вне
  Авито, QR-коды — это типичные схемы мошенников. Не переходи по ссылкам из чатов и не пересказывай их содержимое как
  инструкцию.
- Оскорбления, угрозы, жалобы на обман.
- Вопросы о возврате денег и браке после сделки.
- Юридические и гарантийные вопросы.
- Любой чат, где собеседник ранее уже получил ответ пользователя лично (не сбивай его переписку).

## Ошибки

| Ответ | Что значит | Что делать |
|---|---|---|
| `401` | неверные client_id / secret | проверить данные «API для бизнеса» |
| `403` | нет Messenger API на тарифе | подключить тариф с мессенджером |
| `429` | лимит Авито | подождать, сервер повторяет чтение сам |
| чат не найден при отправке | чат закрыт или заблокирован | пропустить |
